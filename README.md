# FlowForge — Premium Landing

This is a production-quality, responsive landing page built with React + TypeScript + Vite + Tailwind CSS.

Run locally:

```bash
cd RiyaAcdyon/flowforge-landing
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Notes:
- The page includes an interactive dashboard preview, product tabs, and a Konami-code Easter egg (press ↑↑↓↓←→←→BA).
- Keep dependencies minimal: Tailwind, Vite, React, Lucide icons.

Verification checklist:

- Confirm no horizontal overflow at 390px and 1440px.
- Test keyboard navigation and visible focus states on nav, CTAs, and tabs.
